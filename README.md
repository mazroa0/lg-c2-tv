# واجهة عائلية لشاشة LG C2

واجهة شاشة رئيسية مخصّصة بطابع عائلي، مصمّمة لتلفاز LG OLED C2 بمقاس ١٩٢٠×١٠٨٠،
بثيم خريفي وخط ثمانية ومواقيت صلاة محسوبة فلكيًا لمدينة الرياض.

صفحات مستقلة تمامًا: HTML و CSS وجافاسكربت عادي، بلا أي حزم أو أدوات بناء.
افتح `index.html` في أي متصفح وستعمل مباشرة.

## الصفحات

| الملف | المحتوى |
| --- | --- |
| `index.html` | الشاشة الرئيسية: التحية والساعة، شريط مواقيت الصلاة بعدّ تنازلي حيّ، أبرز مباريات الأسبوع، التطبيقات الأكثر استخدامًا |
| `family.html` | قائمة مهام العائلة مع إسناد المهام للأشخاص، تقويم شهري هجري/ميلادي، المواعيد القادمة |
| `settings.html` | إعدادات سريعة: وضع الصورة، السطوع والصوت، مفاتيح تشغيل |

التنقل بين الصفحات عبر الأشرطة على حافتي الشاشة، أو بسهمي اليمين واليسار في الريموت.

## ما تقوم به الواجهة فعليًا

- **مواقيت الصلاة** تُحسب في المتصفح بإحداثيات الرياض على طريقة أم القرى
  (الفجر ١٨٫٥°، والعشاء بعد المغرب بتسعين دقيقة)، بلا اتصال بأي خدمة خارجية.
  الصلاة القادمة تُبرَز تلقائيًا، والعدّ التنازلي يتحدث كل ثانية، وبعد العشاء
  ينتقل إلى فجر الغد.
- **التاريخ الهجري** عبر `Intl.DateTimeFormat` بتقويم أم القرى.
- **الوضع الليلي** بزر الهلال في رأس الصفحة أو من صفحة الإعدادات، ويُحفظ
  الاختيار في `localStorage` فيبقى ثابتًا بين الصفحات.
- **قائمة المهام** تعمل فعلًا: أضف مهمة بالكتابة ثم Enter، وأسندها لأحد أفراد
  العائلة، واضغط المهمة لتعليمها منجزة.
- **التقويم** يعلّم اليوم الحالي ويقبل إضافة موعد لأي يوم.
- **أوراق الخريف** المتساقطة حركة CSS خالصة، وزمنها محسوب من الساعة الفعلية حتى
  لا تقفز إلى بدايتها عند إعادة رسم الصفحة.

المهام والمواعيد والمباريات الظاهرة الآن بيانات توضيحية للتصميم، تُستبدل
بالبيانات الحقيقية عند ربط الواجهة بمصدر بيانات.

> البيانات كلها في ذاكرة المتصفح ولا تُحفظ بعد إغلاق الصفحة، عدا اختيار الوضع
> الليلي. ربط التخزين الدائم خطوة لاحقة.

## التشغيل على التلفاز

أسرع طريقة: ارفع المجلد على GitHub Pages ثم افتح الرابط في متصفح التلفاز.

```
Settings → Pages → Branch: main → / (root)
```

الطريقة الأمتن أن تصبح تطبيقًا داخل التلفاز عبر وضع المطوّر في webOS
(`ares-package` ثم `ares-install`). تنبيه: **webOS لا يسمح باستبدال الشاشة
الرئيسية** — أقصى ما يمكن أن تفتحها من قائمة التطبيقات أو عند التشغيل.

## البنية

```
index.html          الشاشة الرئيسية
family.html         مهام ومواعيد العائلة
settings.html       الإعدادات السريعة
assets/runtime.js   محرّك عرض صغير: {{متغيرات}} و sc-for و sc-if وترقيع DOM
assets/fonts/       خط ثمانية (Sans و Display) بصيغة woff2
```

كل صفحة تحمل قالبها داخل وسم `<template>` ومنطقها في صنف `Component` أسفلها،
ويتولى `runtime.js` ربط الاثنين وإعادة الرسم عند تغيّر الحالة. إعادة الرسم
ترقّع الشجرة القائمة ولا تستبدلها، فلا يفقد حقل الإدخال نصّه ولا تركيزه.

## المقاسات

التصميم مبني على ١٩٢٠×١٠٨٠ ثابتة، ويُقاس تلقائيًا ليملأ أي شاشة مع الحفاظ على
النسبة، فيظهر سليمًا على التلفاز وعلى شاشة الحاسب وعلى الجوال.

## الخطوط

خط **ثمانية** مضمّن في `assets/fonts` بوزني Sans و Display. إن تعذّر تحميله
تسقط الواجهة على خط النظام تلقائيًا.
